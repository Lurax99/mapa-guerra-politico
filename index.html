Cómo llevar datos reales a este mapa

Esta web funciona sin servidor con un motor de simulación. Para enchufar tweets reales necesitas tu propia tubería (la API de X exige claves de pago):

  1. Lanza el filtered stream de la API de X en tu backend con reglas como ("#PSOE" OR "#PP" OR "#VOX" OR "#Sumar" OR "#Podemos") lang:es -is:retweet.
  2. Reenvía cada tweet por WebSocket como JSON: {"text":"...", "user":{"name":"Ana","handle":"@ana"}, "location":"Madrid", "engagement":{"likes":120,"retweets":30}}.
  3. En el panel izquierdo elige WEBSOCKET, pega la URL (ws://localhost:8787/tweets) y conecta. El mapa infiere partido (hashtags/keywords) y comunidad (ubicación) si no se los envías.

Los pesos electorales y los textos de la simulación son datos de demostración, no mediciones reales de opinión pública.
